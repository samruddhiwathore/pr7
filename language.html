Welcome!

Learn the basics of different programming languages with simple notes and examples.

C

C is a general-purpose programming language commonly used for system and application development.

Example

#include <stdio.h>

int main() {
    printf("Hello World!");
    return 0;
}

C++

C++ is a powerful language that supports object-oriented programming.

Example

#include <iostream>
using namespace std;

int main() {
    cout << "Hello World!";
    return 0;
}

Java

Java is a popular object-oriented language used for applications, web development, and Android.

Example

class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}

Python

Python is a beginner-friendly language used for web development, automation, AI, and data science.

Example

name = "John"
print("Hello", name)

JavaScript

JavaScript is mainly used to make websites interactive and dynamic.

Example

let name = "John";
console.log("Hello " + name);

HTML

HTML is used to create the structure of web pages.

Example

<h1>Hello World!</h1>
<p>Welcome to my website.</p>

CSS

CSS is used to style and design HTML web pages.

Example

body {
    background: lightblue;
    color: black;
}

SQL

SQL is used to store, manage, and retrieve data from databases.

Example

SELECT * FROM students;
